대형 게임 팩은 검증된 저장소 조각에서 읽고, 변경 없는 팩은 캐시에서 사용합니다.

## 1.2.1 발견물 이벤트 편집 테스트

- 발견물 이벤트의 조건과 명령을 분류별 목록에서 추가하거나 교체할 수 있습니다.
- 일반 동영상과 발견 애니메이션의 폴더 및 ID를 분리했습니다. 기존 이벤트 14곳은 같은 영상을 재생합니다.
- 편집기에서 불러온 사용자 동영상을 이벤트의 동영상 재생 명령에 지정할 수 있습니다.

## 1.2.1 테스트 갱신

- 메인 메뉴의 편집에 도시 편집을 추가했습니다. 도시 이름, 이미지, 연결 도시, 국가, 문화권, 초기 상태와 도시 이벤트를 설정할 수 있습니다.
- 시설에 발견 이벤트를 연결할 수 있습니다. 시장, 조선소, 교역소가 있는 도시에서는 해당 탭의 판매 품목과 교역 설정을 편집할 수 있습니다.
- 교역권은 일반 교역품 목록에서 선택합니다. 저장한 초기 도시 정보는 새 게임부터 적용됩니다.
- 도서관 책 화면과 힌트 삽화를 2배 해상도 이미지로 표시합니다.
- 책 UI 13개와 힌트 삽화 20개를 분리하고, 삽화 파일 번호를 힌트 구조체의 `book_illustration_id` 0~19에 맞췄습니다.
- 책 모서리는 원본 기반으로 2배 확대하고 경계를 부드럽게 처리해, 원래 색감과 접힌 위치·비율을 유지합니다.
- `OPENBOOK.CDS` 파일 의존성을 제거하고 배포에서도 제외합니다.

검증 범위는 컴파일·리소스 임포트·배포 패키지 및 HTTP 파일 확인입니다. 플레이 테스트는 수행하지 않았습니다.

## 1.3.0 테스트 갱신 — 2026-11-16

- 해상·육상 이동에 방향키를 추가하고 기존 숫자 키 이동을 유지했습니다.
- 새 발견물 등록에서 그룹 번호를 발견물 이름 목록으로 선택합니다. 맨 위의 새 그룹 번호를 선택하면 저장을 확정할 때 번호를 생성합니다.
- 이벤트 편집에 이전·다음 이동을 추가했습니다. 미저장 변경을 확인하고 조건·명령 탭을 유지합니다.
- 발견물 편집의 중복 탭을 정리하고 힌트·책·주점 힌트는 각각의 편집 메뉴에서 관리합니다.
- 새 발견물을 도시 진입 이벤트에서 검색·선택·저장할 수 있도록 했으며 도시·시설의 발견 완료 판정을 함께 확인했습니다.
- 소스 기준 3065b79와 작업 중인 변경을 함께 빌드했습니다. 정확한 소스 파일·팩·네이티브 해시는 site/build-version.json에 기록했습니다.

컴파일·임포트·내보내기·패키지 및 HTTP 정적 검사를 통과했습니다. 플레이 테스트는 수행하지 않았습니다.

## 1.3.3 테스트 갱신 — 2026-11-18

- 도시 그림을 최대 2배(800×640)로 표시하고 테두리와 시설 클릭 영역도 함께 확대했습니다. 작은 화면에서는 전체 도시가 들어오도록 배율을 조절합니다.
- 최신 1.3.3 소스에 현재 작업 중인 발견물 편집 변경을 합쳤습니다.
- 발견물 등록의 그룹을 이름 목록에서 선택하며, 새 그룹은 등록 확정 시 생성합니다. 등록 화면에서는 이전·다음 버튼을 숨깁니다.
- 도시·시설 발견물은 지도 범위 없이 작성할 수 있으며 도시·시설 이벤트에 연결할 수 있습니다.
- 새 발견물 이벤트의 템플릿 버튼으로 기존 이벤트를 복사하고, 복사한 자기 발견물 참조를 새 대상에 맞춥니다.
- 정확한 소스 변경 파일과 리소스 팩·네이티브 해시는 `site/build-version.json`에 기록했습니다.

컴파일·임포트·내보내기·패키지 정적 검증 및 격리된 편집기·도시 UI 검증을 수행했습니다. 플레이 테스트는 수행하지 않았습니다.
