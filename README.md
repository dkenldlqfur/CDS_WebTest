# CDS95 웹 테스트

[웹 테스트 실행](https://dkenldlqfur.github.io/CDS_WebTest/)

대형 게임 팩은 검증된 저장소 조각에서 읽고, 변경 없는 팩은 캐시에서 사용합니다.

## 1.2.1 테스트 갱신

- 도서관 책 화면과 힌트 삽화를 2배 해상도 이미지로 표시합니다.
- 책 UI 13개와 힌트 삽화 20개를 분리하고, 삽화 파일 번호를 힌트 구조체의 `book_illustration_id` 0~19에 맞췄습니다.
- 선택한 첫 번째 고화질 모서리 이미지를 유지합니다.
- `OPENBOOK.CDS` 파일 의존성을 제거하고 배포에서도 제외합니다.

검증 범위는 컴파일·리소스 임포트·배포 패키지 및 HTTP 파일 확인입니다. 플레이 테스트는 수행하지 않았습니다.
