## 1.4.11 world-preset 편집기 테스트 (2026-11-27)

- 기본 데이터는 모든 프리셋에 포함되며, 사용자가 추가한 항목은 사용할 프리셋을 여러 개 지정할 수 있습니다.
- 새 항해사·여급 등록의 프리셋 선택 대상을 초기화하고, 프리셋 버튼 높이와 목록 창의 표시 순서·포커스 복귀를 수정했습니다.
- 스토리 편집은 `이벤트 → 스토리 → 편집 → 스토리 선택 → 스토리 지정`으로 진행합니다. 선택한 스토리의 주인공이 참조하는 프리셋에서 편집 선택지를 읽습니다.
- 스토리 이벤트의 프리셋 지정을 제거했습니다. 스토리와 대사는 공통으로 저장하며, 기존 프리셋별 스토리 편집 자료를 보존하면서 통합합니다.
- 환경 편집은 선택한 프리셋에 저장됩니다. 기본값 복원도 해당 프리셋의 기본 환경을 사용합니다.
- 주점·여관에서 항해사를 해고하는 기능과 재고용 비용 증가를 반영했습니다. 팝업 종료 후 남은 가상 키 입력, 도서관의 비활성 페이지 버튼 입력과 임시 버퍼 누적을 수정했습니다.
- 오류 후 다시 시도할 때 이전 오디오 요청이 새 실행을 막는 문제를 수정했습니다.
- 웹 코드 재컴파일, 리소스 팩 무결성, 모바일 입력과 WASM 연결의 정적 검증을 통과했습니다. 플레이 테스트는 수행하지 않았습니다.

## 1.4.5 웹 리소스 메모리 절감 (2026-11-25)

- 시설·이벤트 애니메이션·이펙트의 판정 마스크를 원본과 같은 값으로 압축하고, 테스트 자료와 중복 시작 화면을 시작 팩에서 제거했습니다.
- 도서관을 포함한 시설 배경과 일기토 그림의 모바일 텍스처 메모리를 줄였습니다. 시설이나 일기토 화면을 닫을 때 사용하던 텍스처를 해제합니다.
- 모바일 시작 팩은 252.3 MiB에서 220.3 MiB로 줄었습니다. 내장 BGM 28곡과 효과음 50개를 포함합니다.
- 웹 재시작 리포트에 시설·일기토의 화면 준비 단계를 기록합니다. 배포 파일은 정적으로 검증했습니다.

## 1.4.5 웹 메모리 및 재시작 진단 (2026-11-25)

- 검증을 마친 리소스 팩과 단일 경로 영상 파일은 가상 파일 시스템에서 다운로드 버퍼를 재사용합니다. 리소스 팩당 최대 약 32 MiB의 임시 복사본을 줄입니다.
- 재시작 리포트에 마지막 게임 단계, WebAssembly에 할당된 메모리 크기와 WebGL 컨텍스트 손실 횟수를 기록합니다.

## 1.4.5 오디오 내장 테스트 (2026-11-25)

- 배경음 28곡과 효과음 50개를 시작 리소스 팩에 넣었습니다. 재생 중에는 팩에서 음원을 읽습니다.
- 캐시가 없는 첫 실행에서 받는 데이터는 약 109 MiB 늘어납니다.

## 1.4.5 테스트 (2026-11-25)

- 웹에서 플레이 중 세션이 끊기면, 같은 탭에서 다음 게임을 시작할 때 마지막 실행 버전·작업·시각을 오류 로그에 남깁니다. 자동 전송은 기본으로 켜져 있습니다.
- 시작 영상 플레이어를 종료할 때 화면을 즉시 숨기고 Godot의 삭제 큐에서 정리합니다.
- 직전 웹 테스트 1.4.1 이후의 JSON 저장 슬롯·항해 기록, 여급 편집, 초상화, 이벤트 편집과 주인공 편집·조선소 매각 오류 수정도 포함합니다.

## 1.2.1 발견물 이벤트 편집 테스트

- 발견물 이벤트의 조건과 명령을 분류별 목록에서 추가하거나 교체할 수 있습니다.
- 일반 동영상과 발견 애니메이션의 폴더 및 ID를 분리했습니다. 기존 이벤트 14곳은 같은 영상을 재생합니다.
- 편집기에서 불러온 사용자 동영상을 이벤트의 동영상 재생 명령에 지정할 수 있습니다.

## 1.2.1 테스트 갱신

- 메인 메뉴의 편집에 도시 편집을 추가했습니다. 도시 이름, 이미지, 연결 도시, 국가, 문화권, 초기 상태와 도시 이벤트를 설정할 수 있습니다.
- 시설에 발견 이벤트를 연결할 수 있습니다. 시장, 조선소, 교역소가 있는 도시에서는 해당 탭의 판매 품목과 교역 설정을 편집할 수 있습니다.
- 교역권은 일반 교역품 목록에서 선택합니다. 저장한 초기 도시 정보는 새 게임부터 적용됩니다.
- 도서관 책 화면과 힌트 삽화를 2배 해상도 이미지로 표시합니다.
- 책 UI 13개와 힌트 삽화 20개를 분리하고, 삽화 파일 번호를 힌트 구조체의 `book_illustration_id` 0~19에 맞췄습니다.
- 책 모서리는 원본 기반으로 2배 확대하고 경계를 부드럽게 처리해, 원래 색감과 접힌 위치·비율을 유지합니다.
- `OPENBOOK.CDS` 파일 의존성을 제거하고 배포에서도 제외합니다.

검증 범위는 컴파일·리소스 임포트·배포 패키지 및 HTTP 파일 확인입니다. 플레이 테스트는 수행하지 않았습니다.

## 1.3.0 테스트 갱신 — 2026-11-16

- 해상·육상 이동에 방향키를 추가하고 기존 숫자 키 이동을 유지했습니다.
- 새 발견물 등록에서 그룹 번호를 발견물 이름 목록으로 선택합니다. 맨 위의 새 그룹 번호를 선택하면 저장을 확정할 때 번호를 생성합니다.
- 이벤트 편집에 이전·다음 이동을 추가했습니다. 미저장 변경을 확인하고 조건·명령 탭을 유지합니다.
- 발견물 편집의 중복 탭을 정리하고 힌트·책·주점 힌트는 각각의 편집 메뉴에서 관리합니다.
- 새 발견물을 도시 진입 이벤트에서 검색·선택·저장할 수 있도록 했으며 도시·시설의 발견 완료 판정을 함께 확인했습니다.
- 소스 기준 3065b79와 작업 중인 변경을 함께 빌드했습니다. 정확한 소스 파일·팩·네이티브 해시는 site/build-version.json에 기록했습니다.

컴파일·임포트·내보내기·패키지 및 HTTP 정적 검사를 통과했습니다. 플레이 테스트는 수행하지 않았습니다.

## 1.3.3 역사 이벤트 편집 테스트 — 2026-11-18

- **편집 → 이벤트 → 역사 → 편집**에서 기존 역사 이벤트 79개의 조건, 명령, 소식 문장을 편집할 수 있습니다.
- 기존 이벤트에서 쓰는 항목과 함께 월간 역사 이벤트에서 실행할 수 있는 공용 항목 및 도시 문화권 변경 같은 역사 전용 명령을 제공합니다.
- 이번 테스트 빌드는 앞서 롤백한 도시 2배 확대와 아이폰 회전 지연 처리 변경을 제외했습니다.
- 소스 기준과 패키지 해시는 `site/build-version.json`에 기록했습니다.

## 1.3.3 역사 이벤트 조건·명령 목록 갱신 — 2026-11-18

- 월간 역사 이벤트에서 사용할 수 있는 조건 42종과 명령 162종을 추가·교체 목록에 표시합니다.
- 발견물 등록·이름 입력·전용 삽화와 성문 잠입·도주 판정은 역사 이벤트의 추가·교체 목록에서 제외했습니다. 역사 이벤트가 사용하는 발견 기록과 힌트 항목은 해당 목록에서 선택할 수 있습니다.
- 부관 고용과 의뢰 화물 판정을 추가하고, 이전 저장에 포함된 기준 연도 미만 분기는 연도 범위 분기로 읽습니다.

## 1.3.3 해전 화면·의뢰 난이도 테스트 — 2026-11-18

- 좁은 웹 화면에 맞춰 해전 영역을 배치하고 해전 중 주변 지도 겹침을 방지했습니다.
- 발견물 힌트에 의뢰 난이도 1~5단계 설정을 추가했습니다.

## 1.3.5 PC 창 모드 글자·UI 배율 수정 — 2026-11-20

- PC에서는 캔버스를 물리 픽셀의 정수 배율로 표시하고 시작 위치를 픽셀 경계에 맞춥니다. 창 크기에 따라 여백이 생길 수 있습니다.
- 모바일 축소·회전·키보드 처리는 유지하며 기존 1.3.5의 게임 코드·리소스 팩을 사용합니다.
- 화면 배율 검사 277개와 모바일 회귀 검사를 통과했습니다. 플레이 테스트는 수행하지 않았습니다.
- 패치 식별자는 `build-version.json`의 `web_shell_patch.id = desktop-pixel-fit-1`입니다.
- 이후 빌드에서도 `tools/desktop-pixel-fit.patch`의 소스 변경을 유지해야 합니다. CI가 실제 HTML의 픽셀 배율을 검사합니다.
